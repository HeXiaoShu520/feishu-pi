- 所有外部依赖通过构造函数注入（如 `LarkTransport`、`PermissionBroker`、`FeishuPiRuntime`），避免模块内全局单例，便于测试时替换。
- 配置统一由 `loadConfig()` 从环境变量解析为强类型 `FeishuPiAppConfig`，必填项缺失时抛错，可选项带默认值或空数组。
- 卡片回调通过 `onApproval` / `onAskUser` 等回调注册到 `LarkTransport`，并在 `main.ts` 中集中转发给 `PermissionBroker` / `AskBroker` 做服务端 token 与来源校验。
- 异步副作用（如 Agent 处理、卡片发送、断线关闭）一律不 await 主流程，仅记录日志，保证事件分发不被阻塞。
- 可复用资源（ResourceLoader、自定义工具定义）采用懒加载 + Promise 缓存模式（`baseLoaderOnce`、`customToolsOnce`），进程内只创建一次。
- 日志输出统一通过 `utils/logger.ts` 的 logger，并按 `[模块名]` 前缀区分来源，便于生产排查。
