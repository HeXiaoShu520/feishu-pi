入口 `src/main.ts` 作为装配根，按依赖顺序实例化并连接各子系统：先启动 `DataCleaner` 清理过期数据，再创建 `LarkTransport`（基于 `@larksuiteoapi/node-sdk` 的 `WSClient` + `EventDispatcher` 直接处理 `im.message.receive_v1` 与 `card.action.trigger`），并通过回调注入 `PermissionBroker`（管理员授权卡）、`AskBroker`（选项卡）和 `UserAuthService`（Device Flow /login）。`FeishuPiRuntime` 封装 `@earendil-works/pi-coding-agent` 的 `createAgentSession`，在 `preload()` 中一次性加载 Skills、自定义工具与权限策略；`ConversationManager` 负责多会话编排，`FeishuAgentBridge` 将飞书消息桥接到对话并挂载 `/perm`、`/login`、`/logout` 等命令。权限体系由 `permission/policy.ts`（`.agent/permissions.json` 驱动组与工具白名单）+ `guard/broker.ts`（待授权队列 + 卡片回调校验）+ `guard/tool-guard.ts`（调用前 OpenAI 兼容审核接口）三层构成。配置集中由 `config.ts` 从环境变量解析为 `FeishuPiAppConfig`，`schedule/service.ts` 通过 croner 调度定时任务并以卡片形式推送结果。统计与配置页面通过 `stats/skill-usage-store.ts` 与 `config-server.ts`（Express）暴露 HTTP 路由。数据持久化统一落在 `data/` 目录下的 JSON/JSONL 文件（sessions、messages、user-tokens、schedules、skill-usage）。
