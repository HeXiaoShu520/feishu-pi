## 1. 使用的系统与方案

本项目采用 **纯环境变量 + 本地文件** 的配置方式，未引入任何配置框架（如 `@dotenvx`、`config`、`conf` 等）。核心依赖仅 `dotenv`（用于启动时加载 `.env`），并通过一个内嵌的 Express 服务器提供浏览器端的 `.env` 编辑界面。

- 配置来源：进程环境变量（由 `dotenv/config` 在入口最先加载）+ 工作目录下的 `.env` 文件。
- 持久化载体：`.env` 文件（位于 `process.cwd()` 下），由内置 Web 服务直接读写。
- 运行时注入：通过 `loadConfig()` 将环境变量映射为强类型 `FeishuPiAppConfig`，再注入到各子系统（飞书 Client、Transport、Runtime、Guard、PermissionPolicy 等）。
- 策略/权限配置：工具调用权限统一放在项目根目录的 `.agent/permissions.json`（由 `PermissionPolicy` 读取），不再使用已废弃的 `FEISHU_CMD_WHITELIST`。

## 2. 关键文件与包

| 文件 | 作用 |
|---|---|
| `src/config.ts` | 定义 `FeishuPiAppConfig` 接口与 `loadConfig(env)` 解析函数，集中声明所有环境变量名、必填/可选语义与默认值 |
| `src/main.ts` | 应用入口，调用 `loadConfig()` 获取配置并装配 Runtime、Transport、Guard、PermissionPolicy、ScheduleService 等组件；同时打印配置页面地址 |
| `src/config-server.ts` | 本地 Express 服务器（监听 `127.0.0.1:3456`），提供 `/api/config` GET/POST 读写 `.env`，以及 `/stats` 技能统计页面 |
| `src/config-page.html` | 配置界面的前端 HTML（含表情选择器、密码显示切换等），通过 `/api/config` 与后端交互 |
| `.env.example` | 示例环境变量清单，列出所有可配置项及注释说明 |
| `package.json` | 脚本 `start` / `dev` 通过 `tsx src/main.ts` 启动；`postinstall` 执行 `scripts/patch-pi-ai.js` |
| `scripts/start.js` | 启动脚本（如有额外包装逻辑） |

## 3. 架构与约定

### 3.1 配置加载顺序
1. 入口 `src/main.ts` 首行 `import "dotenv/config"`，让 `dotenv` 自动从 `process.cwd()/.env` 加载键值对到 `process.env`。
2. 随后调用 `loadConfig(process.env)`，把环境变量转换为结构化对象。该函数内部用 `required(name)` 强制校验必填项，缺失则抛错阻止启动。
3. 非必填项提供默认值（如 `modelProvider = "anthropic"`、`modelName = "claude-sonnet-4-6"`、`guardTimeoutMs = 15_000`、`approvalTimeoutMs = 5 * 60_000`、`cwd = process.cwd()`、`sessionDir = ${process.cwd()}/data/sessions`）。
4. 配置对象被注入到：
   - 飞书 SDK `Client({ appId, appSecret })`
   - `LarkTransport`（imageCacheDir、filesCacheDir、topicRootsFile 均基于 `sessionDir`）
   - `PermissionPolicy`（策略文件路径 `join(config.cwd, ".agent", "permissions.json")`）
   - `ToolGuard`（审核接口 baseUrl/models/apiKey/timeout）
   - `DataCleaner`（清理 `sessionDir`）
   - `SkillUsageStore`（统计文件位于 `dirname(sessionDir)/stats/skill-usage.jsonl`）

### 3.2 配置项分组与命名约定
- 飞书凭据：`FEISHU_APP_ID`、`FEISHU_APP_SECRET`、`FEISHU_ADMIN`（支持中文名/英文名/open_id/邮箱）
- Agent 运行参数：`FEISHU_PI_CWD`、`FEISHU_PI_MODEL_PROVIDER`、`FEISHU_PI_MODEL_NAME`、`FEISHU_PI_MODEL_BASE_URL`、`FEISHU_PI_MODEL_API_KEY`、`FEISHU_PI_SYSTEM_PROMPT`
- 授权超时：`FEISHU_APPROVAL_TIMEOUT_MS`
- 智能体审核（Guard）：`FEISHU_GUARD_BASE_URL`、`FEISHU_GUARD_MODELS`（逗号分隔）、`FEISHU_GUARD_MODEL`（兼容单值）、`FEISHU_GUARD_API_KEY`（回退到 `FEISHU_PI_MODEL_API_KEY`）、`FEISHU_GUARD_TIMEOUT_MS`
- 已废弃：`FEISHU_CMD_WHITELIST`（仍解析但仅输出弃用警告，规则迁移至 `.agent/permissions.json`）

### 3.3 本地配置界面（Web 编辑器）
- 服务器绑定 `127.0.0.1:3456`，仅本机访问（安全约束：明文返回 App Secret，不能暴露到局域网）。
- `MANAGED_KEYS` 白名单控制表单可编辑的键：`FEISHU_APP_ID`、`FEISHU_APP_SECRET`、`FEISHU_ADMIN`、`FEISHU_RANDOM_EMOJIS`、`FEISHU_PI_MODEL_PROVIDER`、`FEISHU_PI_MODEL_NAME`、`FEISHU_PI_MODEL_BASE_URL`、`FEISHU_PI_MODEL_API_KEY`、`FEISHU_PI_SYSTEM_PROMPT`。
- 保存时 `stringifyEnv()` 只重写这些受管键，其他键（如 `FEISHU_GUARD_*`、`FEISHU_TEAM_MEMBERS` 等）原样保留追加，避免丢失。
- 前端 `config-page.html` 提供富文本表单（密码掩码、表情网格多选、全选/反选等），通过 `/api/config` 读取和提交。

### 3.4 运行时热切换
- `LarkTransport` 提供 `onModelSwitch` 回调，当模型切换时调用 `runtime.setModelName(name)`，实现不重启服务的热切换模型名称。

## 4. 约定与约束

- **必填环境变量**：`FEISHU_APP_ID`、`FEISHU_APP_SECRET` 必须在 `process.env` 中存在，否则 `loadConfig()` 抛出 `Missing required environment variable` 错误，进程无法启动。
- **配置文件位置**：`.env` 必须位于 `process.cwd()` 下；可通过 `FEISHU_PI_CWD` 改变 Agent 工作目录，但 `.env` 始终在项目根目录。
- **策略文件位置**：工具权限策略固定位于 `<cwd>/.agent/permissions.json`，不再支持通过环境变量配置命令白名单。
- **安全约束**：配置界面仅监听 `127.0.0.1`，因为 `/api/config` 会明文返回 App Secret 等敏感信息。
- **向后兼容**：`FEISHU_GUARD_MODEL`（单值）与 `FEISHU_GUARD_MODELS`（逗号分隔多值）同时支持；`FEISHU_GUARD_API_KEY` 未设置时回退到 `FEISHU_PI_MODEL_API_KEY`。
- **默认值策略**：所有非必填项均有明确默认值或空字符串，保证最小可用配置即可启动。
- **数据目录约定**：会话、消息、图片、用户、统计、定时任务等数据统一以 `data/` 子目录组织，路径均由 `config.sessionDir` 派生，便于迁移和清理。
- **退出行为**：收到 `SIGINT`/`SIGTERM`/`SIGBREAK`（Windows）后，先停止清理定时器与调度服务，异步断开飞书连接，500ms 宽限期后 `process.exit(0)`，确保优雅关闭。
