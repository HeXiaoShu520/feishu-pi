- 配置集中由 `src/config.ts` 的 `loadConfig()` 从 `process.env` 读取并校验必填项，可选字段提供默认值或回退逻辑。
- 进程优雅退出统一通过 `process.on('SIGINT'|'SIGTERM'|'SIGBREAK')` 注册钩子，先清理定时器与服务再 `setTimeout` 宽限期后 `process.exit(0)`。
- Express 路由按功能拆分：配置页面 HTML 与统计页面 HTML 以静态文件形式引入，API 路由通过函数导出（如 `registerSkillStatsRoutes`）在主服务启动时注册。
- 日志输出统一通过 `./utils/logger.ts` 的 `logger.info/warn` 方法，而非直接 `console.log`。
- 对外部依赖的错误处理采用 try/catch + 降级策略（如获取 Bot Open ID、管理员 Open ID 失败仅 warn 并继续）。
- 环境变量键名遵循 `FEISHU_*` / `FEISHU_PI_*` / `FEISHU_GUARD_*` 前缀分组，便于在配置界面中以 `MANAGED_KEYS` 白名单形式管理。
