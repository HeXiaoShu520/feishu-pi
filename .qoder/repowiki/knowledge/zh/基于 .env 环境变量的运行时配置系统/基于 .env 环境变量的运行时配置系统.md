## 1. 系统概览

本项目采用**纯环境变量驱动**的配置方案，核心入口为 `src/config.ts` 中的 `loadConfig()`。应用启动时通过 `dotenv/config`（在 `src/main.ts` 顶部引入）自动加载根目录 `.env` 文件到 `process.env`，再由 `loadConfig()` 解析为强类型 `FeishuPiAppConfig` 对象供全应用消费。

此外，项目内置一个本地 HTTP 配置界面服务（`src/config-server.ts`），监听 `127.0.0.1:3456`，提供 Web 表单读写 `.env` 文件，并附带技能使用统计页面。该服务仅绑定回环地址，避免敏感凭据暴露到局域网。

## 2. 关键文件与职责

- `src/config.ts`：定义 `FeishuPiAppConfig` 接口与 `loadConfig(env)` 函数，负责从 `process.env` 读取、校验、转换所有运行时配置。
- `src/utils/env-file.ts`：纯函数式 `.env` 文件解析/序列化库（`parseEnvFile` / `stringifyEnv`），被配置页服务复用；维护 `MANAGED_KEYS` 白名单，区分“表单可编辑键”和“手工保留键”。
- `src/config-server.ts`：Express 服务器，提供 `/`（配置页面）、`/api/config`（GET/POST 读取/保存 `.env`）、`/stats` 与 `/api/stats/events`（技能统计）。
- `src/main.ts`：应用主入口，调用 `loadConfig()` 获取配置后组装运行时各组件（飞书 Client、Transport、PermissionPolicy、ToolGuard、ScheduleService 等）。
- `.env.example`：官方示例环境变量清单，作为部署模板。
- `src/config-page.html` / `src/stats-page.html`：静态 HTML 页面，由配置服务器直接返回。

## 3. 架构与设计约定

### 3.1 配置来源与优先级

| 来源 | 说明 |
|---|---|
| `.env` 文件 | 唯一持久化配置源，由 `dotenv/config` 在进程启动时注入 `process.env` |
| `process.env` | 运行时环境变量（容器/平台注入场景） |
| 默认值 | `loadConfig()` 对可选字段提供合理默认（如 `modelProvider=anthropic`、`modelName=claude-sonnet-4-6`、`guardTimeoutMs=15000`、`approvalTimeoutMs=300000`） |

### 3.2 必填字段强制校验

`loadConfig()` 内部通过 `required(name)` 闭包实现：**任何缺失的必填环境变量会直接抛出 `Error`**，阻止应用启动。当前必填项包括 `FEISHU_APP_ID`、`FEISHU_APP_SECRET`。

### 3.3 动态组归属解析

通过扫描所有以 `FEISHU_GROUP_` 开头的环境变量，动态构建 `groupMembership` 映射（组名 → 成员标识列表）。组名不区分大小写，成员支持 open_id、中文名、英文名，逗号分隔。`FEISHU_ADMIN` 会自动加入 `admin` 组。

### 3.4 废弃字段兼容

`cmdWhitelist`（原 `FEISHU_CMD_WHITELIST`）仍保留解析逻辑，但启动时会输出弃用警告，引导迁移至 `.agent/permissions.json`。

### 3.5 配置页服务的“受管键”机制

`src/utils/env-file.ts` 的 `MANAGED_KEYS` 集合定义了 Web 表单可直接编辑的键（如 `FEISHU_APP_ID`、`FEISHU_PI_MODEL_*`、`FEISHU_PI_SYSTEM_PROMPT` 等）。`stringifyEnv()` 在保存时：
- 按固定顺序写入受管键；
- **原样追加**不属于该集合的现有键（如 `FEISHU_GUARD_*`、`FEISHU_APPROVAL_TIMEOUT_MS`、`FEISHU_GROUP_*`），避免手工配置丢失。

### 3.6 安全约束

- 配置服务器仅监听 `127.0.0.1`，注释明确声明“接口明文返回 App Secret，不能暴露到局域网”。
- 路径均基于 `process.cwd()` 拼接，依赖部署时正确设置工作目录。

## 4. 约定与约束

1. **所有运行时配置必须通过环境变量提供**，禁止硬编码；新增配置需在 `FeishuPiAppConfig` 接口与 `loadConfig()` 中同步添加。
2. **必填环境变量缺失即启动失败**（抛错），不允许静默降级。
3. **`.env` 是唯一持久化配置载体**，Web 配置页仅做读写代理，不引入数据库或独立配置中心。
4. **组归属通过 `FEISHU_GROUP_<NAME>` 前缀动态发现**，无需预注册组名。
5. **模型切换热更新**：通过 `onModelSwitch` 回调将新模型名写回 `.env` 并通知运行时，实现运行时切换而不重启。
6. **权限策略与命令白名单解耦**：`cmdWhitelist` 已废弃，工具权限统一由 `.agent/permissions.json` + `FEISHU_GROUP_*` 控制。
7. **数据目录结构约定**：`data/sessions` 存放会话，`data` 存放用户 token 等非会话数据，均由 `config.sessionDir` / `config.dataDir` 导出，其他模块不得自行拼路径。
8. **优雅退出**：`main.ts` 捕获 `SIGINT`/`SIGTERM`/`SIGBREAK`，清理定时器、停止调度、断开连接后最多等待 500ms 强制退出。

## 5. 适用性判断

本仓库存在完整的环境变量加载、校验、Web 配置界面、`.env` 序列化/反序列化、动态组解析等配置相关代码，属于明确的配置系统实现，因此本类别适用。
