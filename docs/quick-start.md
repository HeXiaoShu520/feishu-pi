# 首次运行

本分支提供默认人格、配置模板、扫码向导，以及本工程本机图库的全量表情原图、索引与逐图描述。素材各自的上游许可证、来源与署名保持不变。不需要重新下载原图或运行视觉标注脚本。

## 安装

1. 安装最新 Node.js 22.x 或更新版本、Python 3.11+、Git，建议 Windows。
2. 克隆 README 指定的 release 分支，进入目录并运行 `npm ci`。
3. 运行 `python -m pip install -r requirements-stickers.txt`。
4. 运行 `npm run setup`，扫码创建或绑定自己的飞书应用。
5. 在生成的 `.env` 填写管理员 Open ID、模型名称、接口地址与密钥。模型必须支持图片输入和工具调用，名称与服务要匹配。
6. 飞书后台若提示待发布，先完成发布。
7. 运行 `npm run doctor`，通过后运行 `npm start`。
8. 私聊发“你好”和一张普通图片，验证文本与视觉，再测试表情回复。

模型服务、飞书账号和网络需使用者自行准备。自检不测试远端鉴权或额度。Python 图像依赖版本来源见 [Pillow](https://pypi.org/project/pillow/)。

## 资源范围

工程根目录 `stickers/` 随分支包含全量原图及已有描述，约2.27 GB。建议按 README 使用 `--depth 1` 克隆减少历史下载。表情按索引检索，未被索引收录的图片不会自动成为发送候选。所有上游许可和使用限制原文保留，本工程许可证不替代各素材的原始授权。

收藏表情的入站识别依赖当前电脑的飞书客户端先加载图片，并在 `.env` 显式设置该账户的 `resources/stickers` 路径。不能照抄作者电脑的路径；没有桌面客户端的服务器可能无法使用此能力。普通图片不依赖这个缓存。

## 本机数据

`.env`、`data/`、`work_space/`、`node_modules/`、浏览器登录态、用户画像和运行时人格快照不随库发布。用户画像按人共用，聊天历史仍隔离；画像不授予管理员权限。

B站、浏览器、其他 MCP 与主动发言为可选功能，基础聊天不需要先安装它们的依赖。详细配置见 README。工具审核默认保留，未配置审核模型时回退本人确认。
