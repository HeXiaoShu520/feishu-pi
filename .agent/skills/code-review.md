# Code Review Skill

提供全面的代码审查服务，检查代码质量、安全漏洞、性能问题和最佳实践。

## 审查内容

当用户请求代码审查时，按以下维度进行分析：

### 1. 代码质量
- 命名规范（变量、函数、类名是否清晰）
- 代码结构（是否模块化、职责是否单一）
- 代码复杂度（是否有过度嵌套、过长函数）
- 重复代码（DRY 原则）

### 2. 安全性
- SQL 注入风险
- XSS 漏洞
- 命令注入
- 敏感信息泄露（API Key、密码等）
- 输入验证

### 3. 性能
- 算法复杂度
- 内存泄漏风险
- 不必要的循环或计算
- 数据库查询优化

### 4. 最佳实践
- 错误处理是否完善
- 日志记录是否合理
- 注释是否充分
- 测试覆盖

## 输出格式

审查结果按优先级分类：

**🔴 严重问题**：安全漏洞、严重 bug
**🟡 建议改进**：性能优化、代码质量提升
**💡 提示**：可选的最佳实践建议

每个问题包含：
- 问题描述
- 所在位置（文件:行号）
- 修复建议
- 示例代码（如适用）
